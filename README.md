
# Student Grading System - ICT111

This is my ICT111 assignment for managing student marks.

## Features
- Add Student: Enter student number, name, and marks
- Auto Grading: 
  A (80-100) = Excellent
  B (70-79) = Very good
  C (60-69) = Good
  D (50-59) = Pass
  E (0-49) = Fail
- Display: Counts how many students got each grade (A,B,C,D,E) and shows all students
- Class Summary: Shows Highest mark, Lowest mark, and Class Average

## How to run
python student_system.py
